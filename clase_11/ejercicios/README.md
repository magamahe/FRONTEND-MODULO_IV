# Actividad 1 – Sincronizar inputs
• Crear dos inputs en componentes distintos.
• Hacer que ambos muestren el mismo texto usando estado
elevado.
• Tip: el estado debe estar en el componente padre.

---

# Actividad 2: Lista de tareas
compartida
• El componente App tiene un estado tareas (array de
strings).
• Un componente Formulario permite agregar tareas.
• Un componente Lista las muestra todas.
• Objetivo: practicar cómo elevar el estado para centralizar
la lista.

---

# Actividad 3: Contador global
• El componente App tiene un contador en su estado.
• Crear dos botones en componentes diferentes:
- Uno que incremente el contador.
- Otro que lo decremente.
• Mostrar el valor en App.

---

# Actividad 4: Encuesta interactiva
• El componente App guarda en el estado la respuesta
elegida.
• Crear un componente Pregunta con varias opciones
(ejemplo: botones).
• Crear un componente Resultado que muestre cuál fue la
respuesta seleccionada.
• Objetivo: consolidar el paso de props entre múltiples
niveles
