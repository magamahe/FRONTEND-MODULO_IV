# Clase 5 Extras: Práctica con Componentes

## Actividad 1: Lista de productos

- Crear un array de productos con nombre y precio
- Renderizar la lista en un componente ListaProductos.
- Mostrar con && un mensaje "Producto en oferta" si el precio es menor a 100.

---

## 📝 Actividad 2: Perfil de usuario

- Crear un objeto usuario con: nombre, edad y estado (usar enum con: ACTIVO, INACTIVO, INVITADO).
- Renderizar un componente que muestre:

1. El nombre del usuario.
2. Si es menor de edad, mostrar "👶 Usuario menor de edad".
3. El estado usando condicionales.

---

## 📝 Actividad 3: Renderizado de lista condicional

- Crear un array de tareas con: id, texto y completa.
- Renderizar solo las tareas incompletas.
- Mostrar un mensaje "🎉 No hay tareas pendientes" si todas están completas.
